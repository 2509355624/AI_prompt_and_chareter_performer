# AI 提示词生成器实施计划

## 1. 项目设置
- 初始化 Node.js 项目 (`package.json`)
- 安装最小化依赖: `express` (Web 服务器), `axios` (HTTP 客户端), `body-parser`, `dotenv` (环境变量管理).

## 2. 后端架构 (`server.js` & `ai_service.js`)
- **`ai_service.js`**:
  - 抽象 `AIService` 类/模块。
  - 实现 `generateWithOllama(model, topic, count, baseUrl)` 用于本地 Ollama 实例。
  - 实现 `generateWithApiKey(apiKey, baseUrl, model, topic, count)` 用于标准 API 提供商 (DeepSeek, OpenAI 等)。
  - 实现 `generateWithDoubao(topic, count)` 用于火山引擎 (Doubao) 集成 (读取后端配置)。
  - 提示词工程 (Prompt Engineering): 使用系统提示词 (System prompt) 确保 AI 输出结构化的 JSON 或严格的列表格式，便于提取。
- **`server.js`**:
  - 提供 `public/` 目录下的静态文件服务。
  - API 端点: `POST /api/generate`
    - 接收: `{ provider, apiKey, baseUrl, model, topic, count }`
    - 返回: `{ prompts: [...] }`
  - API 端点: `GET /api/models` (获取 Ollama 模型列表)

## 3. 前端实现 (`public/index.html`)
- **单页应用 (Single Page Application)**:
  - **配置区域**: 切换 "Doubao (火山引擎)", "本地 Ollama" 和 "自定义 API"。包含 Base URL, API Key, 模型名称的输入框 (根据选择自动显示/隐藏)。
  - **输入区域**: "画面主题/描述" 的文本区域。
  - **输出区域**: 以卡片列表形式展示生成的提示词。
- **样式**: 简洁、干净的 CSS (Flexbox/Grid 布局)。

## 4. 自动化与细节
- 后端负责提示词格式化 (强制 JSON 输出)。
- API 调用失败的错误处理。
- 环境变量管理 (`.env`) 用于存储敏感信息。
